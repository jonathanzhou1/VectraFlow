# VectraFlow

As a researcher for the Database Group at Brown University, I collaborated with a team of three PHD students and undergraduates to develop VectraFlow, a stream processing system built to support scalable, low-latency monitoring for vector streams. We documented this research in a paper that was accepted to CIDR 2025 (Conference for Innovative Data Systems Research 2025).

Although the code for the project is currently private, this repository contains the publicly available [paper](https://github.com/jonathanzhou1/VectraFlow/blob/main/VectraFlow_CIDR_CR.pdf).

You can also read the paper on [VLDB](https://vldb.org/cidrdb/papers/2025/p23-lu.pdf).
